====================================================================
3) CHECKLIST POS-MUDANCA (EXECUCAO OBRIGATORIA)
====================================================================
3.1 Sanidade de servicos
- docker ps: n8n/evolution/redis/postgres/minio up
- n8n health: /healthz
- evolution health: / e /manager
- router health: /health

3.2 Sanidade de workflow
- workflow principal ativo
- conexoes corretas entre:
  Normalize Payload -> Resolve Recipient API -> Router Decision -> Guardrails
  AI Allowed? -> OpenAI Responses / Build Fallback Reply
  Extract Reply + Fallback -> Router Learn -> Can Send? -> Evolution Send Text

3.3 Regressao de negocio
- caso 1: saudacao simples (sem travar)
- caso 2: triagem completa de revenda
- caso 3: bloqueio por ineligibilidade (CNPJ/loja fisica)
- caso 4: liberacao book apos elegibilidade
- caso 5: vitrine sob anuencia expressa
- caso 6: B2B sob anuencia expressa com credenciais corretas
- caso 7: pedido de categoria com imagens variadas (sem repeticao rigida)
- caso 8: mensagem marcada (reply-to) com resposta contextual

3.4 Regressao de qualidade de texto
- sem emojis
- resposta curta e coerente com a pergunta
- sem nome inventado
- sem repetir saudacao em toda mensagem

3.5 Logs e rastreabilidade
- registrar o que foi alterado
- registrar motivo
- registrar impacto esperado
- registrar como reverter
